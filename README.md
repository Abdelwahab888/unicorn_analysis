# 🦄 Unicorn Companies Analysis

## 📌 Project Overview
Exploratory Data Analysis (EDA) on a dataset of unicorn companies (startups valued at over $1 billion). This project focuses on identifying, analyzing, and handling missing data, then answering business questions for an investor.

## 🎯 Business Questions
1. Companies in the **Hardware** industry based in **Beijing**, **San Francisco**, or **London**
2. Companies in the **Artificial Intelligence** industry based in **London**
3. Top 20 countries by **sum of company valuations** (excluding US, China, India, UK)
4. Global valuation map of all countries except the "big four"
5. Separate map for Europe

## 🛠️ Tools & Libraries
- Python 3
- pandas, numpy
- matplotlib, seaborn
- plotly.express
